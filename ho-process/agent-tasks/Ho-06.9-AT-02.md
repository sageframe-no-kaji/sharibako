**Required Changes**

1. **`ProjectSidebar`.** `List(selection: $model.selection)` over
   `model.projectSections`; section header = `title` plus a trailing count
   in `inkTertiary`. Rows: glyph (`status.symbolName`, tinted per Decision
   8: notProtected `inkSecondary`, protected `inSync`, outOfDate `drift`,
   problem `drift`, noFolderHere `inkTertiary`; shared rows use `link` in
   `inkSecondary`), then the name, line-limited, middle-truncated; `.help`
   = `status.helpText`. Every row is selectable and tagged with its
   `Selection`. No verbs inside rows (they moved to the pages and the action
   column). Footer unchanged. Entirely empty sections → one
   `ContentUnavailableView("Nothing here yet", description: "Rescan to find
   projects, or use New… to add one.")`.
2. **Window kind switch.** In `WorkshopWindow`, the `NavigationSplitView`
   content column renders: `.project` → `ProjectHeader` over `SecretList`
   (detail column: `SecretDetail`, as today); `.candidate` →
   `NotProtectedPage`; `.problem` → `ProblemPage`; `.shared` →
   `SharedSecretPage`; `nil` → `ContentUnavailableView("Select a project")`.
   For the three page kinds the detail column shows an empty `Color.ground`
   (Discovery lean: the page takes the content width; if the split view
   fights it, collapse the detail column for those kinds and record which).
   `.task(id: model.selection)` on the content column calls
   `loadSecrets` for `.project` and `loadCandidatePreview` for `.candidate`.
3. **`ProjectHeader`.** One strip: status glyph + `status.label` in
   `.headline`, then "· N lines differ" for `.outOfDate(n)`, then the
   abbreviated directory (reuse the model's abbreviation helper from
   `WorkshopModel+Waymarking.swift`) or "No folder on this Mac" in
   `inkTertiary`. Flat `ground` background, 16 pt insets, a bottom
   `Divider`.
4. **`NotProtectedPage`.** Title = project name (`.title2`), "Not protected"
   under it in `inkSecondary`, the directory path (middle-truncated, full
   path in `.help`). Then "N lines in .env" and a list of
   `candidatePreview.keys` in monospace with `••••••••` on the right (never
   a value). Warnings from the preview in `drift` if any. One prominent
   button "Protect <name>" (`primaryActionButton()` treatment from
   `SecretDetail` — reuse or lift into a shared modifier) calling
   `Task { await model.beginIngest(directory:) }`. A quiet "Open in Finder"
   link below. Loading state while the preview is nil: a `ProgressView`
   with "Reading .env…".
5. **`ProblemPage`.** For `.orphaned(scope, markerURL)`: title = scope,
   "Problem" under it, the folder path, then the explanation from the ho
   drawing verbatim, then two buttons: "Protect this folder" (primary;
   `createScopeFromMarker`) and "Forget this folder" (rust `drift`;
   `requestRemoveStrayMarker`), plus "Open in Finder". For `.failed(url,
   reason)`: title "Unreadable claim file", the path, "Sharibako could not
   read the `.sharibako` file in this folder:" and the reason in monospace,
   then "Open in Finder" only.
6. **`SharedSecretPage`.** Title = shared ID, "Shared secret" under it,
   then "Used by N project(s):" followed by one line per `usedBy` tuple as
   "<scope> (<KEY>)", or "Not used by any project yet." Then the sentence
   "Changing a shared secret once changes it for every project that uses
   it. Editing shared secrets arrives with linking." No verbs.
7. **Open in Finder.** A small shared helper (`openInFinder(_ url: URL)`
   in a `Support/` file or on the page) that calls `NSWorkspace.shared.open`
   and `model.announceJump(to:)`; the pages and AT-03's column both use it.
8. **Words.** Every string added here is from the ten words. Status
   labels come from the model (`ProjectStatus.label`), not retyped.
