**Required Changes**

1. **`Selection`.** `enum Selection: Hashable { case project(scopeID: String);
   case candidate(directory: URL); case problem(markerPath: String);
   case shared(id: String) }`. Stored as `var selection: Selection?` whose
   `didSet` performs today's `selectedScopeID` cascade (clear
   `selectedSecretKey`, `revealedValue`, `revealedNotes`, `cachedSecrets`,
   `cachedHistory`) whenever the value changes. `selectedScopeID` becomes a
   computed `String?`: get returns the `.project` payload or `nil`; set
   assigns `.project(scopeID:)` or `nil`. Every existing call site compiles
   unchanged.
2. **`ProjectStatus` and `ProjectEntry`.** `enum ProjectStatus: Equatable {
   notProtected, protected, outOfDate(keyCount: Int), problem(UnlinkedMarker),
   noFolderHere }` with `symbolName`, `label` (the status word in the ten
   words: "Not protected", "Protected", "Out of date", "Problem", "No folder
   on this Mac"), and `helpText`. `struct ProjectEntry: Identifiable,
   Equatable { id: Selection; name: String; directory: URL?; scopeID: String?;
   status: ProjectStatus }`. `struct ProjectSection: Identifiable { id: Kind;
   title: String; entries: [ProjectEntry] }` with kinds notProtected,
   projects, needsAttention, sharedSecrets in that fixed order.
3. **Derivation.** `var projectSections: [ProjectSection]`, pure over
   `scopes`, `scanReport`, `driftReports`, `candidates`, `sharedIDs`:
   - Not protected: each `candidates` URL → entry named by last path
     component, `.notProtected`.
   - Projects: each scope → `.outOfDate(n)` when `driftReports[id]` is
     drifted (reuse `isDrifted` / `driftedKeyCount`), else `.protected` when
     `scanReport` holds its marker, else `.noFolderHere`. Directory = the
     marker's directory when present. Name = `displayName ?? identity`.
     Sorted by name.
   - Needs attention: each `unlinkedMarkers` element → `.problem(marker)`,
     named by the orphan's scope (or "Unreadable claim file" for `.failed`),
     directory = the marker's directory, id `.problem(markerPath:)`.
   - Shared secrets: each `sharedIDs` → entry with id `.shared`, no
     status rendering needed (status `.protected` is acceptable as a
     placeholder but must not be shown; document it).
   Empty sections omitted. `projectStatus(forScope:)` and
   `projectEntry(for: Selection)` as lookups.
4. **Caches.** `private(set) var candidates: [URL] = []`,
   `private(set) var sharedIDs: [String] = []`,
   `private(set) var linkGraph: [String: [(scopeID: String, key: String)]]`
   (or an `Equatable` struct wrapper if the tuple array fights
   `@Observable`). `loadScopes()` fills `sharedIDs` and `linkGraph`
   (failures → `errorMessage`, as scopes do today).
   `usedBy(sharedID:) -> [(scopeID: String, key: String)]` sorted by scope.
5. **Candidates in the scan.** `performLaunchScan()` and `rescan()` compute
   `IngestCandidateScanner.findUnboundCandidates(under: roots)` inside the
   same `worker.run` closure as the marker scan and store both. Rescan's
   status: "Found N project(s) to protect; M already protected." where M is
   the number of scopes with a marker in the report — singular/plural
   handled, zero stated plainly ("Found no projects to protect; 4 already
   protected."). The launch scan stays quiet.
6. **Launch selection (Decision 4).** After `performLaunchScan()` stores its
   results and `selection == nil`: first Not-protected entry, else first
   Projects entry, else leave `nil`. A pure `static func initialSelection(
   sections:) -> Selection?` tested directly, applied once.
7. **Protect commit.** `commitIngest()` on success removes the session's
   directory from `candidates` (standardized path compare), splices the
   marker into the cache as today, and sets `selection = .project(scopeID)`.
   No chaining. `confirmRemoveStrayMarker()` on success re-runs the scan +
   candidates hop quietly (no status line change beyond today's announce).
8. **Candidate preview.** `private(set) var candidatePreview:
   CandidatePreview?` (`directory`, `keys: [String]`, `warnings: [String]`)
   and `func loadCandidatePreview(for directory: URL) async` running
   `Materializer.ingest(directory:)` on the worker; cleared when the
   selection changes. Keys only — no values leave the worker hop; the page
   masks everything anyway.
9. **Chooser retirement.** Delete the members listed under Files; delete
   `IngestChooserSheet.swift` and its tests; remove the two view call sites
   and the first-run invite; wizard preview copy: "Found N project(s) with a
   .env file — they'll be waiting under Not protected." and the button is
   always "Create Vault". `Activity.ingesting.label` → "Protecting…".
10. **Tests.** Every status from fixtures (candidate dir with `.env`; scope
    with marker; scope with marker + drifted report injected via the
    existing heal test pattern; orphan marker; malformed marker; scope with
    no marker); section order and omission; `initialSelection` for each
    case; the selection cascade through `selection` and through the
    `selectedScopeID` shim; `candidates` filled by `performLaunchScan` and
    `rescan`, pruned by a commit (reuse the ingest-commit test fixture);
    `sharedIDs` / `usedBy` from a vault with a linked key; `candidatePreview`
    keys from a fixture `.env`; the reworded Rescan status line.
