# Ho-06.9-AT-03 — Contextual action column and the New… menu

**Goal**

Make the right-hand action column contextual: one group titled with the
selected thing's name holding only its verbs, a VAULT group of four, and one
**New…** menu replacing the three Add buttons. Remove the last traces of the
old noun-grouped panel and the chooser. Reconcile CI. Run the full rhythm and
the Xcode build.

**Required Changes**

1. **Selection group.** Title = `model.selectionTitle` uppercased (the
   project name, the candidate folder name, the orphan's scope, or the
   shared ID); omitted entirely when nothing is selected. Verbs by kind,
   exactly per Decision 7:
   - `.candidate`: **Protect** (`beginIngest(directory:)`), **Open in
     Finder**.
   - `.project` protected / out of date: **Write .env**
     (`materializeSelectedScope`), **Preview .env** (`previewEnv`), **Open
     in Finder**, **Delete project** (rust, `requestDeleteSelectedScope`).
   - `.project` no folder here: the same four, with Write / Preview / Open
     disabled and `.help` = "No folder on this Mac — attach one in a later
     version" (plain words; AT-01's `writeDisabledReason`).
   - `.problem` orphaned: **Protect this folder** (`createScopeFromMarker`),
     **Forget this folder** (rust, `requestRemoveStrayMarker`), **Open in
     Finder**.
   - `.problem` unreadable: **Open in Finder**.
   - `.shared`: group omitted (no verbs this ho).
   All disabled while `model.activity != nil`, as today.
2. **VAULT group.** **Rescan** (today's behaviour incl. the first-root
   picker; message "Choose the folder where you keep your projects"),
   **Sync**, **Check all** (`checkDrift`; help "Check every protected
   project's .env against the vault — one Touch ID"), **Write all out of
   date** (`requestMaterializeAllStale`; enabled only when
   `model.hasOutOfDateProjects`; help "Rewrite every out-of-date .env from
   the vault").
3. **New… menu.** One `Menu` button styled like `actionButton` (titled
   "New…", `plus`) with three items: **Project** (opens the Add Scope
   window), **Secret in <project>** (opens the Add Secret window with the
   selected scope ID; disabled unless `.project` is selected, title then
   "Secret"), **Shared secret** (opens the Add Shared Secret window). The
   menu is the one allowed menu: these are rare, by-hand creations, not
   the journey.
4. **Removal.** The SCOPE / VAULT / ADD headers, "Ingest Project…",
   "Materialize", "Materialize All Stale", "Check Drift", "Jump to
   Directory", "Delete Scope" are gone from this file. The `panelWidth`
   stays 212 unless "Write all out of date" wraps badly at body size; if
   so, widen to 228 and say so in the commit body.
5. **Appearance** control unchanged.
6. **Full rhythm + Xcode build**, then a run of the app from the built
   bundle is NOT required of this task (the orchestrator gates it), but
   `xcodebuild … build` must succeed.
