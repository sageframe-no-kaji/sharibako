# Ho-06.10-AT-03 — The one project page

**Goal**

Render AT-02's lines model as the single page every project gets, protected
or not (ho-06.10 Decision 6): a header with the large red mark and one
Protect button when secrets are unprotected, the lines list with secrets
first and the settings folded below, a detail pane that shows a protected
line as today and an unprotected line or setting with its value, class,
reason, and plain-words choice (Decision 7), and right-click menus. Remove
the Not-protected page.

**Context**

`ho-process/hos/ho-06.10-protect.md` Decisions 6–7 and the sketch in
ho-06.9's document for the frame. AT-02 landed: `projectLines`,
`secretLines`, `settingLines`, `headerState` (`label`, `symbolName`),
`selectedLineKey`, `selectedLine`, `setLineChoice(_:forKey:)`,
`protectLine(key:)`, `protectRecommended(scopeID:)`,
`protectAllCandidates()`, `paneError`, `LineChoice.label`,
`ProjectLine` (`value`, `status`, `reason`, `choice`). Existing views:
`Views/WorkshopWindow.swift` (the kind switch), `Views/ProjectHeader.swift`,
`Views/SecretList.swift`, `Views/SecretDetail.swift` (keep; it is the
protected-line detail, incl. `primaryActionButton()`),
`Views/NotProtectedPage.swift` (`PageTitle`, `OpenInFinderLink` move to a
shared file; the page itself goes), `Views/ProjectSidebar.swift`,
`Views/ActionPanel.swift` (verbs list from the model), `Color+Theme.swift`.

**Required Changes**

1. **Header.** `PageTitle` (name, folder path) then the state row:
   - `.unprotected(n)`: `xmark.octagon.fill` at 28 pt in `Color.drift`,
     `headerState.label` in `.title3`, and the one prominent button
     `model.protectButtonTitle` (`primaryActionButton()`) calling
     `protectRecommended()`; disabled while `activity != nil`. Right-aligned
     on the same row, or below on narrow widths.
   - `.protected(upToDate)`: `checkmark.circle.fill` in `Color.inSync`,
     label, no button. Out-of-date count in `Color.drift` when present.
   - `.empty`: "No lines" quietly.
   - `model.paneError` renders beneath the state row when set: message in
     `Color.drift`, next step in `inkSecondary`.
2. **Lines list.** A `List(selection: $model.selectedLineKey)`:
   - Secret lines: row = status symbol tinted (`inSync` protected, `drift`
     notProtected, `inkTertiary` missingFromEnv), key in monospace, then on
     the trailing side the value for an unprotected line (monospace,
     middle-truncated, `inkSecondary`) or `••••••••` for a protected one;
     caption line beneath with `reason` for unprotected lines ("secret — key
     ends in KEY") or "in the vault" for protected ones, "in the vault, not
     in .env" for missing.
   - A `Divider` then a disclosure row `model.settingsFoldLabel`
     (`DisclosureGroup`, collapsed by default, state remembered per session
     in `@State`), containing the setting rows: dot symbol, key, value,
     caption reason, all in `inkSecondary`/`inkTertiary`.
   - Empty project: `ContentUnavailableView("No lines", description:
     "This project has no .env lines and nothing in the vault.")`.
   - Each row has a `.contextMenu` from `model.lineVerbs(for:)`:
     unprotected → "Protect this line", "Use shared secret ‹id›" (one per
     shared id, when any), "Make it a shared secret", "Leave in .env as a
     setting"; setting → the same four with Leave checked; protected →
     "Reveal", "Copy", "Delete secret" (existing intents). Verbs dispatch
     to existing model intents; no logic in the view.
3. **`LineDetail`.** For a selected unprotected line or setting: key as
   title (monospace, `.title2`), status word, the value as it stands in
   `.env` (monospace, selectable, full width, "(empty)" for empty), the
   class and reason, then a picker titled "What should Sharibako do?" whose
   options are `LineChoice.label` for the applicable choices (Use shared
   only when shared secrets exist; one option per id, or a sub-picker of ids
   if more than three), bound to `setLineChoice`. Beneath: the action
   button — `protectLine(key:)` titled "Protect this line" when the choice
   protects, or "Leave in .env" disabled-looking text when the choice is
   leave. For `.missingFromEnv`: today's `SecretDetail`.
4. **Window.** Both `.project` and `.candidate` → `ProjectPage`; the detail
   column: `SecretDetail` when `selectedLine?.status` is `.protected` or
   `.missingFromEnv`, `LineDetail` for `.notProtected`/`.setting`, empty
   otherwise. `.task(id: model.selection)` still calls `loadContent`.
5. **Sidebar context menu.** Rows get `.contextMenu` with the same verbs the
   action column shows for that row (Protect / Open in Finder; Write .env /
   Preview / Open / Delete project; Protect this folder / Forget / Open).
   The Not-protected section header gains a trailing "Protect all" link
   calling `protectAllCandidates()` when the section has rows.
6. **Words.** Only the ten words plus Decision 7's labels. No "scope",
   "ingest", "import", "marker" in any string you add.
