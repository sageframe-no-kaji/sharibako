# Ho-06.10-AT-02 — Project lines model

**Goal**

Give `WorkshopModel` the one-page-per-project state (ho-06.10 Decisions 6–7):
for any project, protected or not, the full list of its lines — vault keys
and `.env` lines merged — each with a status, a classifier recommendation,
and a user choice; the header state (red mark + count, or protected); and the
Protect intents (one line, the project's recommended lines, every unprotected
project) over `Materializer.acceptIngest` behind one Touch ID. Retire the
ingest session and sheet. Headless, tested. No new views.

**Required Changes**

1. **Types.**
   `enum LineStatus: Equatable { case protected(kind: SecretInfo.Kind);
   case notProtected; case setting; case missingFromEnv }` — protected = in
   the vault; notProtected = in `.env`, not in the vault, classifier says
   secret; setting = in `.env`, not in the vault, classifier says setting;
   missingFromEnv = in the vault, no line in `.env` (only when a folder is
   known).
   `enum LineChoice: Equatable { case protectLocal; case useShared(id:);
   case makeShared(id:); case leaveAsSetting }` with `var label: String`
   ("Protect for this project", "Use shared secret ‹id›", "Make it a shared
   secret", "Leave in .env as a setting") and
   `func decision(forKey:) -> KeyDecision` (`leaveAsSetting` → `.leaveAlone`;
   `skip` is never produced).
   `struct ProjectLine: Identifiable, Equatable { id: String (the key); key;
   value: String? (plaintext from .env, nil when missingFromEnv); status;
   lineClass: LineClass? (nil when protected); reason: String? ; choice:
   LineChoice? (nil when protected) }`.
   `enum ProjectHeaderState: Equatable { case unprotected(count: Int);
   case protected(upToDate: Bool?) ; case empty }` with `label`
   ("3 secrets not protected", "Protected", "Protected · up to date",
   "Protected · 2 lines differ", "No lines") and `symbolName`
   (`xmark.octagon.fill` / `checkmark.circle.fill`).
2. **Derivation.** `private(set) var projectLines: [ProjectLine]` and
   `var headerState: ProjectHeaderState`, filled by `loadContent(for:)`:
   - `.project(scopeID)`: `inspect(scopeID)` on the worker for vault keys;
     when `cachedMarker(forScope:)` gives a folder, also
     `Materializer.ingest(directory:)` for `.env` lines. Merge by key:
     vault key present → `.protected(kind)` (value nil — never decrypted
     here); `.env` line not in vault → `.notProtected` or `.setting` by
     `lineClass`; vault key with no `.env` line → `.missingFromEnv`.
   - `.candidate(directory)`: `ingest(directory)` only; every line is
     `.notProtected` or `.setting`.
   - Order: secrets (protected, notProtected, missingFromEnv) in file order
     then vault order for the rest; settings after. `var settingLines` and
     `var secretLines` as filtered reads for the view's fold.
   - Default `choice`: classifier default — secret → `.protectLocal`, or
     `.useShared(id)` when `nameMatchedSharedID` is set; setting →
     `.leaveAsSetting`. Session flips in a `[String: LineChoice]` keyed by
     folder path + key, applied on derivation, cleared when the folder is
     protected.
   - `headerState`: `.unprotected(n)` when any `.notProtected` line exists
     (n = their count); else `.protected(upToDate:)` from `driftReports`
     (nil when unchecked); `.empty` when there are no lines at all.
   - `unprotectedSecretCount`, `isCandidate` (no scope yet) as reads.
3. **Choice setter.** `func setLineChoice(_ choice: LineChoice, forKey:)`
   updates the flip map and the line; `useShared` only when `sharedIDs`
   contains the id.
4. **Protect intents.** All acquire the age key on the main actor once
   (existing provider, reason "Protect secrets in ‹name›"), hop to the worker
   for `acceptIngest`, then refresh scopes + scan cache (splice the marker as
   `commitIngest` did), remove the folder from `candidates`, clear its flips,
   set `selection = .project(scopeID)`, reload lines, announce
   ("Protected 3 secrets in bento; 2 settings left in .env."). Failures land
   in `errorMessage` and, new, in `paneError: PaneError?` (`struct PaneError
   { message: String; nextStep: String? }`) which AT-03/AT-04 render in the
   pane; cleared on selection change.
   - `func protectLine(key:) async` — one line, its current choice.
   - `func protectRecommended(scopeID: String? = nil) async` — every line
     whose choice protects (`protectLocal` / `useShared` / `makeShared`);
     settings are `leaveAlone`. For a candidate the scope ID is
     `scopeID ?? suggestedScopeID(for: directory)`.
   - `func protectAllCandidates() async` — every `candidates` folder with
     its own derived lines and defaults, inside one key handle; announce the
     totals ("Protected 3 projects: 7 secrets; 5 settings left in .env.").
   - `static func suggestedScopeID(for directory: URL, existing: Set<String>)
     -> String`: the folder name lowercased, invalid characters → `-`,
     validated by `VaultCore.isValidIdentifier`; on collision append `-2`,
     `-3`, …. Tested.
   - Scope type for a new project: `.projectDev` (tags are optional and set
     later, Decision 4; no prompt).
5. **Selection.** `selectedLineKey` replaces `selectedSecretKey` as stored
   state with the same cascade; `selectedSecretKey` becomes a computed shim
   returning the key only when the selected line is `.protected` (so
   `SecretDetail`'s reveal path never fires for a plaintext line).
   `selectedLine: ProjectLine?` as a read.
6. **Retirement.** Everything under Files. `beginIngest(directory:)` and
   `protectFolder` end by selecting the folder (candidate or project) — no
   sheet. `createScopeFromMarker` protects with the marker's scope ID.
7. **Tests.** Derivation for every `LineStatus` from fixtures (vault with
   keys, folder with matching and extra lines, a setting, a missing key, a
   candidate folder); defaults incl. a shared name match; the flip map and
   its clearing; header state for each case; `suggestedScopeID` incl.
   collision; `protectLine` / `protectRecommended` / `protectAllCandidates`
   against temp vaults with an ephemeral age key (the existing encryption-
   test convention), asserting vault files, claim file, candidates pruned,
   selection moved, announce text; a failure path landing in `paneError`.
